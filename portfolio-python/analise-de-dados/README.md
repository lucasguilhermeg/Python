# Análise de Dados

Notebooks cobrindo estatística descritiva, correlação, regressão e manipulação de dados com pandas.

## Conteúdo

### [`05_estatistica_descritiva.ipynb`](./05_estatistica_descritiva.ipynb)
Fundamentos de estatística aplicados com pandas:
- Medidas de tendência central: média, mediana, moda
- Medidas de dispersão: variância, desvio padrão, amplitude
- Percentis e quartis com numpy
- Visualizações: histogramas e boxplots
- Criação e manipulação de colunas em DataFrames

### [`06_correlacao_regressao.ipynb`](./06_correlacao_regressao.ipynb)
Relações entre variáveis e modelos preditivos:
- Coeficiente de correlação de Pearson
- Regressão linear com `numpy.polyfit`
- Gráfico de dispersão com reta de regressão
- Coeficiente de determinação R²
- Regressão polinomial e risco de overfitting

### [`07_condicionais_planilhas.ipynb`](./07_condicionais_planilhas.ipynb)
Condicionais aplicadas a planilhas e gráficos:
- Comandos `if`, `elif`, `else`
- Cálculo condicional de médias ponderadas em DataFrames
- Plotagem de parábolas com tratamento dos casos de delta (Bhaskara)
