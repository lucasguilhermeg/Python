# Condicionais Aplicadas a Planilhas e Gráficos

## O que este notebook demonstra

Como usar estruturas condicionais (`if`, `elif`, `else`) em contextos práticos: tomada de decisão sobre dados de planilhas e controle do comportamento de gráficos com base em resultados matemáticos.

## Conceitos abordados

- Estruturas `if`, `elif`, `else` para decisão entre múltiplos caminhos
- Cálculo condicional de médias em DataFrames pandas (simples ou ponderada, conforme input do usuário)
- Atribuição de conceito de acordo com nota final
- Fórmula de Bhaskara com tratamento dos três casos de delta: duas raízes, uma raiz e sem raízes reais
- Plotagem condicional de parábolas com matplotlib e numpy

## Principais aprendizados

Condicionais permitem que o mesmo programa se comporte de formas diferentes dependendo dos dados ou da escolha do usuário. Em análise de dados, isso é útil para calcular métricas diferentes conforme o contexto. No caso de Bhaskara, o sinal do delta determina não apenas o resultado matemático, mas também como o gráfico deve ser delimitado.
