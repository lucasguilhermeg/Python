# Fundamentos de Python

Notebooks introdutórios cobrindo os conceitos base da linguagem.

## Conteúdo

### [`01_fundamentos_basicos.ipynb`](./01_fundamentos_basicos.ipynb)
Conceitos essenciais de Python:
- Comentários e operações matemáticas (`+`, `-`, `*`, `/`, `**`, `//`, `%`)
- Variáveis e atribuição
- Biblioteca `math` (funções como `sqrt`, `factorial`, `gcd`)
- Função `print` e formatação de saída

### [`02_entrada_de_dados.ipynb`](./02_entrada_de_dados.ipynb)
Interação com o usuário via teclado:
- Função `input`
- Conversão de tipos: `str`, `int`, `float`
- Por que `input` retorna texto e como converter para número
