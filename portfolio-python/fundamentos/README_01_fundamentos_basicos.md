# Fundamentos Básicos de Python

## O que este notebook demonstra

Introdução à linguagem Python com foco em operações matemáticas, variáveis e saída de dados. Os exercícios exploram como o Python pode ser usado como uma calculadora programável, resolvendo problemas do cotidiano com poucos comandos.

## Conceitos abordados

- Operações aritméticas: adição, subtração, multiplicação, divisão, potência, divisão inteira e módulo
- Precedência de operadores e uso de parênteses
- Criação e atribuição de variáveis
- Sensibilidade a maiúsculas e minúsculas em nomes de variáveis
- Biblioteca `math`: `pi`, `e`, `factorial`, `sqrt`, `gcd`
- Função `print` e formatação de saída com `%.2f`
- Conversão de tipos: `int()`, `float()`, `math.floor()`

## Principais aprendizados

O Python diferencia letras maiúsculas de minúsculas em nomes de variáveis — `C` e `c` são variáveis distintas. A ordem de atribuição importa: `9/5 + 32 = F` gera erro porque o valor deve ser atribuído à variável, não o contrário. A biblioteca `math` amplia as operações disponíveis para além das aritméticas básicas.
