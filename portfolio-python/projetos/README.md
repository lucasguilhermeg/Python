# Projetos

Projetos completos de análise de dados desenvolvidos durante o curso.

## Projetos

### [`operacoes-financeiras-brasil/`](./operacoes-financeiras-brasil/)
Análise exploratória de dados do Banco Central do Brasil sobre operações financeiras por canal de atendimento entre 2011 e 2023. Utiliza pandas, matplotlib e seaborn para ETL, visualização de tendências, análise de crescimento anual e comparação entre canais.
