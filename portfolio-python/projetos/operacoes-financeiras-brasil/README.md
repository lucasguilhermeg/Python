# Análise de Operações Financeiras no Brasil (2011–2023)

Projeto de análise exploratória de dados sobre o volume de operações financeiras realizadas no Brasil ao longo de 13 anos, segmentadas por canal de atendimento.

## Fonte dos Dados

Banco Central do Brasil, disponibilizado publicamente via Google Sheets.

## Canais Analisados

- Agências e Postos de Atendimento
- ATM (Caixas Eletrônicos)
- Internet Banking
- Telefone Celular (App)

## Análises Realizadas

1. **Tendência geral** — evolução do volume total por canal entre 2011 e 2023
2. **Distribuição por tipo de operação** — comparação dos tipos de operação em cada canal
3. **Taxa de crescimento anual** — variação percentual ano a ano por canal
4. **Análise individual por canal** — detalhamento do volume por tipo de operação ao longo do tempo

## Tecnologias

- Python 3
- pandas, numpy, matplotlib, seaborn
- Jupyter Notebook

## Como Executar

Abra o arquivo `analise_operacoes_financeiras.ipynb` no Google Colab ou Jupyter e execute as células em ordem. Os dados são carregados automaticamente via URL pública.
