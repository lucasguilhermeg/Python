# Visualização de Dados

Notebooks e scripts sobre criação de gráficos com matplotlib e numpy.

## Conteúdo

### [`03_graficos_matplotlib_numpy.ipynb`](./03_graficos_matplotlib_numpy.ipynb)
Introdução à visualização com Python:
- Função `plot` do matplotlib
- Geração de vetores numéricos com `numpy.arange`
- Gráficos de funções matemáticas (polinômios, seno, cosseno)
- Customização: cores, estilos de linha, título, eixos, legenda e grade

### [`04_matplotlib_avancado.py`](./04_matplotlib_avancado.py)
Visualizações mais elaboradas:
- Múltiplos subplots com `plt.subplots`
- Gráficos de barras, pizza e boxplot
- Histogramas com diferentes estilos e paletas de cores
- Uso do estilo `ggplot`
